# PulseTWIN — Digital Heart Monitoring System

A responsive project showcase for a real-time health-care monitoring concept built from January to April 2025.

## Stack

- Unity 3D digital twin environment
- ESP32 microcontroller
- Pulse sensor
- OLED display
- Breadboard and jumper wires

## Run locally

```powershell
cd C:\Users\dasar\DigitalHeartMonitoringSystem
python -m http.server 8001
```

Open http://localhost:8001.
